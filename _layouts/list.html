--- layout: default --- {%- comment -%} Shared layout for list subpages. It lists the .md, .pdf and .txt files in this page's collection directory (_/), one entry per base name, sorted by title when the site is built. When several formats share a base name, only the best one is linked: .md ([Web Page]), then .pdf, then .txt. Essays start as .txt and get converted later, so an older format is stale. In the browser, entry-list.js adds the filter box, the copy-link buttons and any .mp4/.m4a with the same base name from the GitHub release tagged . Records are " ||". The sort key has its spaces replaced by "!" so the space after it sorts before any title character, which keeps "Gnosticism" ahead of "Gnosticism for Dummies".
